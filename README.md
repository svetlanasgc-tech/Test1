# Sol Español
Статический сайт курса испанского языка. Откройте index.html в браузере. Сборка и установка пакетов не нужны.

## GitHub Pages
1. Создайте репозиторий и загрузите содержимое этой папки в его корень.
2. В Settings → Pages выберите Deploy from a branch, ветку main и / (root).
3. После публикации GitHub покажет ссылку на сайт.

## Настройка перед продажами
Название Sol — демонстрационное. Программа A1–C2 — пример, замените её на вашу в app.js. В index.html измените название, описание и ответы на вопросы. В app.js замените обработчик кнопки enroll ссылкой на ваш Telegram, платёжную страницу или сервис записи. Сейчас окно честно сообщает, что запись не подключена. Цены, отзывы и данные преподавателя не выдуманы и не добавлены.

Все уровни рассчитаны на 1,5 месяца каждый; это длительность программы, а не гарантия достижения уровня. Выбор уровня сохраняется только в браузере. Персональные данные сайт не собирает. Шрифты загружаются из Google Fonts; без сети используется системный шрифт. Иллюстрация выполнена в CSS, внешних фотографий нет.
